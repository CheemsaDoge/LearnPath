# 知径 LearnPath · 作品提交材料

> 知乎黑客松 2026 · 校园新锐季 · 方向二「知识炼金场：学习工具与知识生产」

## 一句话介绍

把知乎的高赞回答，变成你的学习路径：输入一个真实的学习目标，生成可视化知识图谱，每个知识点锚定知乎优质内容，用带引用的讲解、测验与费曼评分追踪掌握度，并推荐下一步。

## 我们解决的问题

- 知乎上「讲得最透的内容」是离散的：搜到十篇好回答，不知道先看哪篇、看完算不算懂、下一步学什么。
- 通用 AI 助手会「一本正经地讲」，但学习者无法验证它讲的对不对、来自哪里。
- 学习工具普遍缺少「掌握度」概念：收藏 ≠ 学会。

知径把这三件事串成一个闭环：**结构（图谱）→ 证据（知乎来源）→ 验证（测验与费曼解释）→ 行动（下一步）**。

## 核心功能与演示流程（约 3 分钟）

1. 首页输入目标「我想搞懂 Transformer，能读懂论文和源码」，选择「有一点基础 / 每天 1 小时」。
1a. AI 先追问 2-4 个关键问题（前置知识、目标深度、偏好），点选或自述作答；可上传课程大纲作为路线骨架。
2. 1-3 分钟后得到知识图谱：根节点 → 3-5 个模块 → 10-18 个知识点，前置关系用虚线箭头表示，右下角「下一步」推荐第一站。
3. 点击知识点「自注意力机制」：右侧面板显示 4 篇知乎来源（专栏 / 回答，已读取全文）。
4. 「讲解」标签：流式生成带 [1][2] 角标的讲解，含「知乎观点对照」；点击角标跳回原文。
5. 「小测验」：3 道单选 + 1 道费曼解释；提交后 AI 评分、掌握度变为 ★★☆，图谱节点同步更新，「下一步」推荐变化。
6. 「复习卡片」一键生成；「追问」围绕知识点答疑并引用来源。
7. 顶部「导出」得到 Markdown 学习清单（含全部知乎链接）。
8. 打开「控制台」：学习档案里已自动记录「数学系大二学生 / 会 Python / 目标…」，档案馆按时间列出每一次互动，附件可查看下载。
9. 回到首页：点知乎热榜任一条目「学背后的知识」，把新闻事件转化为知识领域的学习路线。

## 技术实现

- 前端：React 19 + TypeScript + Vite + Tailwind v4，React Flow + dagre 自动布局知识图谱，SSE 流式渲染讲解。
- 后端：FastAPI + SQLAlchemy(SQLite WAL)，后台流水线「目标 → 结构化图谱（LLM structured output）→ 并行检索 + 全文读取 → 就绪」，进度可轮询。
- LLM：Provider 抽象，支持 Anthropic 官方 SDK 与任意 OpenAI 兼容模型（线上使用 deepseek-v4-flash）；离线 Mock 模式保证无 key 也能演示流程。
- 掌握度模型：单选本地判分 + 费曼解释三维评分，加权后指数平滑，映射 0-3 星；模块星级聚合；软解锁 + 下一步推荐。
- 学习档案：每次澄清 / 提问 / 答题 / 上传由模型提取事实（背景、已掌握、目标、偏好），去重后写入档案并注入后续所有 prompt；访客数据在知乎登录时自动合并。
- 稳定性：模型调用隐式重试 + 确定性兜底（来源摘要讲解、通用测验、基础路线骨架），前端自动静默重试与容错轮询。
- 参考：开源项目 LearnGraph 的 G-R-E-M-A 学习闭环。
